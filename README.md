# Dose+

Uma apresentação web interativa sobre segurança na rotina medicamentosa de idosos.

O projeto nasceu para a CP5 de Software & TX Design. A proposta combina pesquisa de UX, acessibilidade e prototipação para responder a uma pergunta simples:

> Como ajudar uma pessoa idosa a seguir sua rotina de medicamentos sem retirar sua autonomia?

## O problema

Quando não existe uma confirmação clara, a memória vira a única fonte de informação. Isso pode gerar dúvida, dependência familiar e risco de uma dose ser esquecida ou repetida.

## A proposta

O Dose+ organiza a experiência em torno de uma ação principal por vez:

- mostra qual medicamento deve ser tomado agora;
- registra a confirmação e o horário;
- mantém um histórico fácil de consultar;
- avisa o familiar somente quando existe um atraso relevante.

## Experiência da apresentação

O site funciona como uma apresentação navegável e inclui:

- contexto e definição do problema;
- persona e mapa de empatia;
- comparação entre a rotina sem e com o Dose+;
- protótipo funcional para paciente e familiar;
- decisões de acessibilidade;
- plano de teste de usabilidade;
- próximos passos do produto.

Use as setas na tela ou as teclas direcionais para avançar. No protótipo, os botões simulam a confirmação da dose, o pedido de ajuda e a visão do familiar.

## Tecnologias

O projeto foi desenvolvido com HTML, CSS e JavaScript puros. Não exige instalação de dependências ou processo de build.

Para executar localmente, abra `dist/index.html` no navegador ou sirva a pasta `dist` com um servidor HTTP.
